# LinguaVoice AI 2.0 — выпуск 1

Голосовой переводчик с казахским интерфейсом: **микрофон или текст → Gemini (распознавание, определение языка, перевод) → Microsoft Edge TTS → звук**.

## Что нового в выпуске 1

- **Новый дизайн:** тёмная тема по умолчанию, стеклянные карточки, сине-фиолетовые градиенты, светлая тема. Анимированная звуковая волна, этапы «Тыңдау → Өңдеу → Аудару → Сөйлеу», уведомления, индикатор подключения.
- **Разделы:** Аудармашы (главный экран), Сұхбат, Тарих, Таңдаулы, Баптаулар. На телефоне меню внизу, на компьютере — боковая панель.
- **AUTO LANGUAGE ON/OFF:** при OFF исходный язык выбирается вручную. Язык речи «закрепляется» только после фразы не короче 3 слов или после двух коротких фраз подряд на одном языке, поэтому кашель или одно чужое слово его не переключают. Числовой уверенности Gemini не даёт, поэтому приложение её не показывает и не выдумывает.
- **Голос (Edge TTS):** фильтр «Бәрі / Әйел / Ер», голоса сгруппированы по акцентам (АҚШ, Ұлыбритания…), скорость, **громкость**. Мужской или женский вариант недоступен, если у Edge TTS нет такого голоса для языка.
- **История 2.0:** поиск, фильтр по типу (дауыс / мәтін / сұхбат) и языку, избранное (☆), удаление, экспорт **TXT** и **CSV** (открывается в Excel с кириллицей). Старая история переносится автоматически, ничего не теряется.
- **PWA:** установка на главный экран, работа без интернета (история и настройки), офлайн-экран, уведомление «Жаңа нұсқа дайын → Жаңарту». Перевод и озвучка без интернета **не работают** — это сервисы Google и Microsoft.
- **config.js:** адрес сервера теперь живёт в отдельном файле. При следующих обновлениях его не нужно вписывать заново.

Следующие выпуски: 2 — Live Subtitles и AI PRO (контекст, стиль, словарь, режимы); 3 — тренажёр произношения.

## Структура

```
index.html, config.js, sw.js, manifest.webmanifest, offline.html
css/app.css
icons/…                       иконки приложения
js/app.js                     запуск, связывает модули
js/router.js, js/state.js     разделы (#/translate …), шина событий
js/net.js                     адрес сервера, HTTP с тайм-аутом, WebSocket
js/speech/                    микрофон + определение конца фразы, сессия записи
js/translation/               ядро перевода, AUTO LANGUAGE
js/voice/                     очередь воспроизведения, голоса Edge TTS
js/storage/                   история (IndexedDB v2 + миграция), настройки
js/ui/, js/views/             интерфейс и экраны
backend/                      FastAPI-сервер (Render) — ключ Gemini только здесь
```

## Как обновить сайт

1. Распакуйте архив. Откройте папку `linguavoice` — внутри `index.html`, `config.js`, папки `css`, `js`, `icons`, `backend` и т.д.
2. На GitHub откройте **главную страницу** репозитория → **Add file → Upload files**.
3. Выделите **всё содержимое** папки `linguavoice` (Ctrl+A) и перетащите в окно браузера. Подождите, пока загрузится список (~55 файлов).
4. **Commit changes**. GitHub заменит старые файлы новыми.
5. Render сам пересоберёт сервер (3–7 минут, статус **Live**). GitHub Pages обновит сайт за 1–2 минуты.
6. Откройте сайт и нажмите **Ctrl+Shift+R**.

`config.js` уже содержит адрес `https://linguavoice-ux4j.onrender.com`. Если адрес сервера когда-нибудь изменится, правьте только этот файл.

## Проверка

`https://linguavoice-ux4j.onrender.com/docs` — в списке должны быть `/api/translate_text` и `/ws`.
Если сайт пишет «Сұрау қате құрылған», сервер ещё старый: Render → **Manual Deploy → Deploy latest commit**.

## Что проверено

- 14 автотестов сервера.
- Браузерный тест (Chromium, имитация микрофона, тестовый сервер вместо Gemini и Edge TTS):
  - перевод голосом и текстом, озвучка по фрагментам, повтор, пересинтез после смены громкости;
  - AUTO ON/OFF, фильтр голосов, диалог;
  - перенос истории версии 1 и сохранение старых настроек;
  - избранное, поиск, фильтры, экспорт CSV (BOM) и TXT, удаление;
  - светлая и тёмная темы, ширина 360/390 px без горизонтальной прокрутки, компьютер;
  - сервис-воркер, кэш, офлайн-режим, обновление версии;
  - браузерный синтез речи не используется, ошибок в консоли нет.
- **Не проверено:** настоящие вызовы Gemini и Edge TTS (в моей среде нет ключа и доступа к ним) и реальные Safari и Firefox (тест был в Chromium).
